# Project: Bookshelf ! ! 📖

### Goal: Create a full-stack app with authentication and CRUD functionality

## Result: A  virtual bookself app that allows you to add books and see what your friends are reading

## Idea: 
* You can see your friends bookshelves by passing in their user ID
* Books can be hidden or displayed publicly on your shelf 
* Default page shows you your bookshelf


## How to Use

1. Check out the [bookshelf app here](https://picky-v3j9.onrender.com/).
2. Create your account / sign up
3. Log in to your account
  
4. Create a Book
  Fill out the following info: 
   *Title
   *Author
   *Date started
   *Progress
   *Display on shelf? Y/N

6. Update your book rating by moving the slider. 
7. You can delete books!
